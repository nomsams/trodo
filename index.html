Trodo Pro Guide

Welcome to Trodo! This is a spatial, real-time Kanban board. Drag the background to pan, and use your mouse wheel to zoom in and out.

Keyboard Shortcuts

  • N - Create a new task
  • Enter - Save task / Confirm dialog
  • Esc - Close modals / Cancel
  • Arrows - Move hovered task (Up/Down/Left/Right)

🤖 Robot / Agent API

Trodo exposes a local API for injected scripts or browser extensions to automate tasks. You must authenticate first.

Your API Code: 
// 1. Authenticate
TrodoAPI.authenticate('YOUR_API_CODE');

// 2. Get Tasks
const todo = TrodoAPI.getTasks('todo');
const myJobs = TrodoAPI.getAssignedTasks('Robot');

// 3. Move & Update
TrodoAPI.moveTask(myJobs[0].id, 'in-progress');
TrodoAPI.updateTask(myJobs[0].id, { desc: 'Processing data...' });

// 4. Chat
TrodoAPI.sendChat('I have started working on the task!');

// 5. Listen for User Changes
TrodoAPI.onTaskUpdated((task) => {
    console.log('Task changed by user:', task);
});
